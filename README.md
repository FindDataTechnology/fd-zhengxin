# fd-zhengxin

政心（zhengxin）独立产品线门面单仓：web 三入口（`/` 官网 landing、`/workbench` 工作台、`/admin` 管理后台）+ FastAPI 服务端（个人层：理解卡/学习地图/理解年轮的自有存储）。

lex 线第四模块骨架任务。技术栈照 fd 舰队配方、形制照姊妹仓 fd-zhesi：React 19 + Vite + TS + Tailwind v4 + i18next 双语；服务端 Python FastAPI；部署 cheap fd-prod + TCR + ArgoCD。

## 产品定位

政心是政治思想理解工具，lex 线第四模块：帮助用户以「理解」而非「表态」的方式进入政治思想史。读原典、问概念、辨脉络，用自己的话复述理解；理解沉淀为理解卡，积累长成学习地图，修订沉积为理解年轮。政心呈现分歧，从不裁断分歧；它增长你的理解力，不替你持有立场。

## 四闭环

政心由四个闭环构成。**读**——面对文本本身：进入原典的语境再谈理解，谁在说、对谁说、回应什么，读到的第一手材料沉淀为理解卡，转述必带来源；**问**——生活语言进、思想史坐标出：用日常的话说出困惑，政心把它映射到政治思想史真正的概念坐标上，澄清锚定参照系引用而非凭空定义；**辨**——分歧并置、不站队：诸家主张放进各自语境并置呈现，看见分歧在哪里、为何分歧、各自付出什么代价，产品只呈现分歧结构，不诱导、不裁断、不替用户选边；**轮**——理解是一部年轮：理解会修订而历史不覆盖，旧理解卡封存进理解年轮，学习地图随积累一版版长成，回头看可见自己理解力生长的痕迹。

## 口径纪律

政心对政治思想内容只做「理解」不做「表态」，纪律落在三处：**模型层**——理解卡不含任何表态字段（无立场/赞同/倾向/评价列，`personal.py` 的 migration 由测试守住）；**呈现层**——呈现即引用、转述优先于评论、分歧并置而不裁断；**守卫层**——内容过 `guard.py` 口径守卫，动作只有两个：拦（BLOCK，不呈现）与标灰（GREY，呈现但置灰降权），每次命中产出结构化原因（rule_id/category/detail）可查，规则库骨架期留空接口、接线期逐条填充。越线内容没有第三种处置，放行也不得伪装成推荐。

## 参照系分库

参照系（政治思想参照系）独立部署、独立存储，本仓不承载参照系实现——照 fd-zhesi 与 fd-zhesi-reference 的分仓先例。服务地址配置留位 `FDZX__REFERENCE_BASE_URL`（见 `server/fd_zhengxin_api/config.py`）；个人层（用户理解记录）只落本仓自有库（默认 `~/.fd-zhengxin/personal.db`，env `FDZX__DB`），与参照系物理分库，永不混入共享底座。

## 骨架期口径

- web 三入口均为真实可渲染占位页（四闭环接线期落工作台界面）
- server 提供 `/healthz`、`/api/version`、`/api/v1/me`（鉴权自检占位）；个人层 API（理解卡/学习地图/理解年轮）挂载点接线期补
- 环境变量统一 `FDZX__` 前缀，集中读自 `config.py`
- 隐私立场：个人层是用户理解记录，只落本仓自有存储，不进共享底座

## 本地开发

web：`cd web && npm install && npm run dev`

server：`cd server && python3 -m venv .venv && source .venv/bin/activate && pip install -e ".[dev]" && pytest && uvicorn fd_zhengxin_api.main:app --port 8011`
